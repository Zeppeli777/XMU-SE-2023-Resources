# 实验二：熟悉服务器环境（验收现场操作指南）

## 一、现场验收可能要求

助教通常要求学生在华为云 Docker Swarm 环境中完成以下验证步骤：

1. 修改 MySQL 数据库密码；
2. 重新构建或部署 `productdemomybatis` 服务；
3. 验证 MySQL 服务与 `productdemomybatis` 服务联通；
4. 展示 Swarm 服务状态、容器日志与数据库表内容。

---

## 二、修改 MySQL 密码及重启服务步骤

**（1）查看 mysql 服务所在节点：**

```bash
docker service ps mysql
```

**（2）进入 mysql 所在节点并查看容器 ID：**

```bash
docker ps | grep mysql
```

**（3）进入容器：**

```bash
docker exec -it [CONTAINER_ID] sh
```

**（4）登录 mysql 并修改密码：**

```bash
mysql -uroot -p
ALTER USER 'demouser'@'%' IDENTIFIED BY '新密码';
FLUSH PRIVILEGES;
```

**（5）退出容器后重新部署服务：**

```bash
docker stack deploy -c productdemomybatis-docker.yml --with-registry-auth lab
```

---

## 三、检查服务与日志

**1. 查看服务状态：**

```bash
docker service ls
```

**2. 查看某个服务的详细运行情况：**

```bash
docker service ps productmybatis
```

**3. 查看容器日志：**

```bash
docker logs [CONTAINER_ID] | tail -n 50
```

---

## 四、常见问题速查

* **服务部署失败** → 检查 `productdemomybatis-docker.yml` 中数据库密码是否与 MySQL 一致。
* **无法连接数据库** → 检查 overlay 网络或 label 是否配置正确。
* **镜像拉取失败** → 检查是否已登录华为 SWR。
* **日志乱码** → 使用 `tail -f` 命令查看实时输出。

---

## 五、命令速查
