# 校选
## 目的驱动选择
### 功利角度
对于想留学的同学来说，校选课是非常重要的，因为唯有留学的情况，校选课的成绩会算到平均成绩中。又因为校选课**一般**考核比较水好拿高分，可以考虑多选些。（部分奖学金/荣誉的评定也看校选，但没必要为此多选）
### 非功利角度
**感兴趣的选就完了！**挂了只要分够也不影响毕业（当然想挂还是有难度的）

## 分类
除了核心目的外，建议从以下几个角度考虑，没有绝对的好坏，结合“目的”，见仁见智：
### 开课院系
文科/医学/艺术：拓展人文素养，调和纯理工的思维。考勤、课堂形式、考核等会比较灵活。
理科：注重逻辑思维或一定的实验能力，考勤、考核等相对难（当然肯定是比专业课低的），也会比较难突击。尽量不要选自己完全提不起兴趣的课程。
工科：和理科差不多。区别是老师一般会待在翔安，要联系他们相对容易些。
经济统计等类：能加深对社会、经济各方面的认知，可以汲取对经济的学习方法，但是校选能讲的终究是有限，若有较强兴趣或需求建议辅修。
### 考核方式
分为考核跟考察。考核就是安排期末考试，一般是最后一堂课，不排在期末周。考察一般是课程论文/大作业/项目等。各有优劣，自行权衡。

# 毕业要求
10学分，注意其中至少2分应为美育。
